# I002 — 격리 도구 설치가 상위 package.json을 변경

- 상태: resolved
- 발견: 2026-10-29 KST, T01 의존성 설치 후 `git status`와 `git diff package.json` 확인.
- 재현: package.json이 없는 `.pages-tools/`에서 npm install을 실행한다.
- 실제: npm이 상위 프로젝트를 선택하여 루트 package.json과 package-lock.json에 도구 의존성을 기록했다.
- 기대: Pagefind·PostCSS 등 보조 CLI는 `.pages-tools/` 안에만 설치되어야 한다.
- 영향: 모노레포 원본 의존성이 오염되고 의도보다 많은 패키지 설치가 발생한다.
- 관찰: 기본 Hugo 빌드는 성공했지만 의존성 설치의 격리 문제가 남는다.
- 다음 조치: 도구 폴더에 private package.json을 만들고 npm에 명시적인 prefix를 전달한다. 제공 inputs 원본은 보존하고 실행 사본 두 곳만 수정한다. 자동 실행으로 생긴 루트 변경은 기준 파일과 비교하여 복원한다.
- 수정: `.pages-tools/package.json`을 명시적으로 생성하고 `npm --prefix <tool_dir> install`을 사용한다. 자동 설치가 만든 루트 manifest 변경은 원본 바이트로 복원했다.
- 재검증: 의존성 재설치가 종료 코드 0으로 완료됐고 도구 폴더에 85개 패키지가 설치됐다. 루트 package.json의 Git diff는 없으며 후속 Hugo 빌드도 종료 코드 0, 홈페이지 포함 93페이지 생성에 성공했다.
