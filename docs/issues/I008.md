# I008 — 반투명 헤더 뒤로 이전 섹션 글자가 비침

- 상태: resolved
- 발견: 2026-10-29 KST, Firefox 섹션별 스크린샷 시각 검토.
- 실제: sticky 헤더의 반투명 배경 아래 이전 섹션의 큰 글자가 겹쳐 보여 메뉴의 시각적 명확성이 떨어진다.
- 기대: 아래 섹션으로 이동해도 헤더의 메뉴는 배경 글자와 구분되어야 한다.
- 재현: `#about`, `#future`, `#current`로 이동하여 상단 메뉴를 확인한다.
- 근거: `docs/evidence/T08/header-before.png`.
- 조치 계획: 불투명한 동일 배경색을 사용해 헤더 뒤 글자를 차단하고 같은 앵커 화면을 다시 확인한다.
- 수정: portfolio.css의 반투명 background와 backdrop-filter 규칙을 제거하고 불투명 아이보리 배경을 유지했다.
- 재검증: 같은 #about 화면에서 뒤의 글자가 비치지 않음을 시각적으로 확인했고, 수정 후 Firefox 20개 검사와 정적 검사가 다시 통과했다. 최종 about 화면과 header-before를 비교할 수 있다.
