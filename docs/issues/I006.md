# I006 — 소스에서 제거한 데모 산출물이 public에 남음

- 상태: resolved
- 발견: 2026-10-29 KST, 개인화 빌드 후 public 디렉터리 점검.
- 실제: site/content의 데모 60개 파일을 제거했지만 이전 빌드의 public/publications/와 public/uploads/resume.pdf가 남아 있다. site/static/uploads/resume.pdf도 원본 데모다.
- 기대: 새 빌드 결과에는 현재 콘텐츠만 존재하고 타인의 데모 이력서·사진이 공개되지 않아야 한다.
- 원인: 제공 빌드 명령은 출력 폴더의 오래된 콘텐츠를 정리하지 않는다. 정적 데모 CV와 사용하지 않는 원본 인물 이미지도 남아 있다.
- 영향: 로컬 미리보기와 새 환경의 빌드가 다르고 의도하지 않은 예시 자료를 공개할 수 있다.
- 다음 조치: Hugo 출력 정리 옵션을 적용하고 정확히 확인한 데모 자산을 제거한 뒤 파일 부재와 두 언어 재빌드를 확인한다.
- 수정: 빌드 사본 두 곳에 `--cleanDestinationDir`를 적용하고 데모 CV와 인물 사진을 정확한 경로로 제거했다.
- 재검증: Windows 빌드 진입점은 종료 코드 0이며 public/publications와 public/uploads/resume.pdf가 모두 없다. 두 언어의 소개·앵커·자산 정적 검사는 통과했다.
