# I018 — 상세 설명을 추가한 작업 카드의 제목 시작선 차이

상태: 수정·로컬 재검증 완료. 2026-11-05 KST. 발견 기록: 9e3d056. 대상은 상세 콘텐츠 작업본이다.

수정: 기존 .flow li를 위에서부터 배치하고 번호 행을 24px로 고정했다. 긴 영문 제목도 의미를 유지해 줄였다. 첫 수정 후 역할 태그의 폰트 기준선 때문에 1px 차이를 추가로 확인해 번호 행 높이를 통일했다. 한국어·영어 1440·900·768·390px 총 8개 검사에서 같은 행의 제목·첫 본문 좌표 차이가 1px 미만이고 가로 잘림이 없음을 확인했다. 수정 후 그림: ../evidence/T08/firefox/flow-detail-after.png. 공개 최종 검사는 기존 results.json에 보존한다.

1440px 영어 화면에서 네 작업 카드에 길이가 다른 설명을 넣으니 제목의 세로 시작 위치가 달라졌다. 기존 .flow li의 align-content: space-between이 번호와 설명 사이에 남은 공간을 배분해 짧은 설명의 제목이 더 내려간다. 일부 긴 영문 제목도 두 줄로 표시된다. 글자 크기·가로 넘침 검사는 통과했으나 제목·본문을 나란히 비교하기 어렵다.

근거: ../evidence/T08/firefox/flow-detail-before.png. 한국어·영어 전체 화면은 로컬 상세 콘텐츠 검사에서 캡처했다.

수정 방향: 기존 카드의 번호→제목 간격을 고정하고 위에서부터 배치한다. 영문 제목은 의미를 유지해 한 줄로 줄이며 본문 크기·행간은 유지한다. 새 폴더·스타일 체계·애니메이션 코드를 추가하지 않는다. 같은 네 폭·두 언어에서 제목/첫 본문 좌표와 실제 화면을 재검증한다.
