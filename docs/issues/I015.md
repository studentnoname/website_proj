# I015 — 잔여 이동 검사에서 렌더 전 좌표를 기준으로 삼음

상태: 원인 확인·검사 수정 전. 2026-11-04 KST.

투명도와 유동적인 추종 움직임을 구현한 뒤 Firefox 61개 검사 중 기존 55개·투명도 2개는 통과했고 양방향 추종 검사 4개는 실패했다. 실제 수집값은 PC 아래 방향에서 0ms drift=0, 80ms=11.33px, 180ms=2.11px, 400ms=0·flow=idle이었다. 위 방향은 음수에서 0으로 복원됐고 모바일도 같은 수렴을 보였다. 애플리케이션의 종료·방향 조건은 충족했다.

새 검사는 scrollBy 직후 첫 requestAnimationFrame 콜백에서 좌표를 읽었다. 이 콜백이 scroll 핸들러가 예약한 render보다 먼저 실행되어 아직 스타일이 반영되지 않은 0을 시작점으로 잡았다. 그 0과 최종 0을 비교해 이동이 없다고 판정했다. I011과 같은 첫 프레임 이전 표본 문제이나 이번에는 별도 추종 검사에서 발생했다.

수정 방향: 두 animation frame을 거쳐 render가 적용된 표본부터 수집한다. 실제 불투명도·방향·위치 변화·400ms 안에 정확한 0 복원·정지 후 프레임 예약 0을 계속 검증한다. 검사 통과를 위해 앱의 움직임을 바꾸지 않는다. 실패 당시 값은 `../evidence/T08/firefox/results.json`에 보존한다.
