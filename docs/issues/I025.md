# I025 — 커밋 집계 근거의 공개 접근성 부족

발견일: 2026-11-07 KST. 상태: 공개 집계·제출 PDF 추가 구간 연결 및 대조 완료.

## 관찰과 영향

피드백을 현재 보고서와 대조하였음. 제출 보고서에는 전체 후보·제외·집계값과 제외 목록이 있지만, 커밋별 전체 SHA·파일·포함 사유를 담은 `release.json`은 무시되는 로컬 제출 폴더에만 있음. 공개 `docs/commit-log.md`도 집계 원칙만 있어 채점자가 개별 포함 판단을 재검토하기 어려움.

## 기대 결과와 계획

기존 `docs/commit-log.md`에 공개 검토 기준 SHA까지의 전체 커밋 목록·변경 파일·포함/제외 이유·diff 링크를 제시함. 기준 SHA 뒤 최종 제출 SHA까지의 추가 커밋은 제출 PDF에서 별도로 제시하여 자기 자신의 SHA를 문서에 넣기 위한 이력 재작성을 피함. 기존 커밋의 실질 변경을 검토하고 자동 산출물만의 변경은 제외함. 학번·이름·비공개 KONNECT 코드는 공개 집계에 넣지 않음.

## 검토 명령의 길이 제한

커밋 diff를 읽는 보조 명령에 모든 변경 경로를 인자로 넣었더니 원본 정리 커밋의 많은 경로 때문에 Windows `WinError 206`으로 실패하였음. 저장소 파일·Git 이력은 변경되지 않았음. 이후 커밋 diff를 한 번 읽고 필요한 원문 경로를 결과에서 선택하여 길이 제한 없이 검토하였음. 공개 집계 생성 명령은 정상 완료하였음.

## 수정과 대조

공개 검토 기준을 `398aa03798ec60bb031ac2b5c8015c5b72072b45`로 고정하고 `docs/commit-log.md`에 전체 후보 125개·제외 3개·포함 122개의 모든 행을 생성하였음. 원본 ZIP 단순 등록, PDF만의 자동 생성, 검증 증거만 보관한 변경을 제외하였음. 나머지 원문·코드·설정 변경은 실제 파일 목록과 변경 내용으로 검토할 수 있도록 SHA·메시지·파일·포함 분류·diff 링크를 공개하였음. 분류 문구는 파일 목록에서 생성한 것임을 함께 밝혔음.

공개 목록의 순서·전체 SHA·파일·포함/제외·개수를 Git 이력과 대조하였음. 추가 구간 출력도 실제 후속 커밋으로 생성해 SHA·파일 경로가 PDF에 포함되는 것을 확인하였음. 최종 합계는 공개 고정 구간과 이후 추가 구간을 합친 값이며, 최종 main push 성공 뒤 release 내보내기에서 확정함. 이 방법으로 자기 SHA를 넣기 위한 amend 없이 전체 집계를 추적할 수 있음.
