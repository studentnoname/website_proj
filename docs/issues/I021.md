# I021 — 채점 재검토의 메뉴 상태 표시와 Git 작성자 공개 범위

상태: 메뉴 수정·새 커밋 개인정보 방지의 로컬 확인 완료, 공개 확인 예정. 과거 Git 작성자 정보는 별도 미해결 범위다. 2026-11-06 KST. 최초 검토 대상 main: 426596ea3a286733aab79ffdec4898b4a5fd5641. 최초 발견 기록 40b0f74는 비공개 로컬 검토 브랜치에만 있었다. ‘최종 제출 상태 말고 나머지는 보완’ 요청에 따라 실제 개인정보 값을 포함하지 않은 이 기록을 작업 브랜치로 가져왔다. 아래 관찰은 수정 전 상태다.

## P49 현재 메뉴 상태 표시

공개 #about을 Firefox 159.0.1에서 1440px·390px로 확인했다. 두 경우 모두 현재 메뉴에 aria-current=location이 있으나, PC의 선택 항목은 글·배경색만 다르고 모든 항목의 굵기 400·밑줄 없음·별도 기호 없음이 같았다. 390px에서 메뉴를 열면 선택 항목과 나머지 항목의 글색·배경·굵기·구분선이 모두 같았다. 접근성 의미 정보와 시각적 상태 표시를 구분한다.

관련 구현: site/assets/css/portfolio.css의 .nav a[aria-current] 및 모바일 .js .nav ul a 규칙. 채점표 P49는 제공한 상태를 색상만으로 전달하지 않도록 요구한다. 따라서 기존 기능 검사 90개·점진적 향상 17개 통과만으로 이 항목의 충족을 단정하지 않는다. 보완안은 현재 항목의 밑줄·굵기 또는 현재 위치 텍스트 등 색 이외의 표시를 PC·모바일에 함께 적용하는 것이다. 이 검토에서는 코드를 수정하지 않았다.

## 공개 Git 작성자 정보

원격 main에 포함된 대표 설정 커밋 65a2d5487cf135bf5585be9dbd6f46727fc5b918을 로그인 없는 GitHub API로 확인했다. 커밋 작성자 이름이 로컬 제출용 한글 이름과 일치하고 작성자 이메일이 GitHub noreply 주소가 아닌 개인 주소였다. 실제 값은 이 문서에 복사하지 않는다.

이는 사이트 본문·추적 텍스트/PDF 패턴 검색의 범위 밖인 Git 메타데이터다. 인증정보나 KONNECT 공격 경로를 발견했다는 의미는 아니다. 과제는 이름·연락처의 일괄 비공개를 강제하지 않으므로 확정 감점으로 판정하지 않되, 제출용 개인정보를 공개 범위에서 분리하려던 사용자 선택과 관련된 확인 사항이다. 기존 Git 이력 보존 규칙 때문에 작성자 정보의 소급 변경·이력 재작성·force push는 수행하지 않았다.

보완 시작 시 인증된 GitHub 계정의 ID와 로그인명으로 noreply 주소를 확인하고, 이 저장소에만 공개 활동명과 noreply 작성자·커미터 설정을 적용했다. 전역 설정은 변경하지 않는다. 이 설정은 이후 커밋에 적용되며 과거 공개 메타데이터까지 지운 것으로 표시하지 않는다. 과거 수정은 COMMIT_POLICY.md의 이력 재작성·force push 금지와 충돌하므로 별도 로컬 사본에서 변경 범위와 검증 결과를 준비한다.

## 보완과 로컬 재확인

공통 CSS의 현재 항목에 굵기 700·2px 밑줄을 함께 적용했다. 기존 hover·배경·초점·메뉴 크기는 유지한다. Hugo 빌드 종료 0, 홈·404 정적 참조 오류 0, Firefox 159.0.1의 1440·390px 실제 메뉴에서 선택된 항목만 굵기 700·밑줄이고 나머지 항목은 굵기 400임을 확인했다. 모바일 전체 화면에서 표시·줄바꿈·항목 간격도 시각 검토했다.

이 저장소의 pre-commit 검사에 공개 활동명·noreply 작성자와 커미터 확인을 설치했다. 예상한 정보는 허용하고 가상 예제 이메일을 주입한 검사는 차단됨을 확인했다. 실제 개인정보 값은 출력·새 문서·화면에 복사하지 않았다. 전역 설정이나 기존 공개 이력을 변경하지 않았다.

## 추가 검사 실행 중 발견한 전제 오류

f4cbfed 공개 실행에서 기존 검사와 새 P49 검사를 합친 90개 중 접이식 메뉴의 연속 선택 검사에서 실패가 있었다. 같은 문서의 #about→#current 이동은 이미 열린 메뉴 상태를 유지하는데, 새 검사가 열림 여부를 확인하지 않고 토글을 다시 눌러 메뉴를 닫은 뒤 보임을 판정했다. 현재 항목의 굵기 700·밑줄은 올바르게 적용되었고 실패 표본의 visible만 false였다. 테스트가 메뉴 열림을 확인한 뒤 필요한 경우에만 열도록 수정하고 같은 두 언어·네 폭을 다시 확인한다. 제품의 열림 동작을 검사 편의에 맞게 바꾸지 않는다. 점진적 향상 17개와 상세 배치 8개는 같은 공개 CSS에서 통과했다.

## 이번에 확인한 충족 근거와 한계

README의 현재 Windows 빌드 명령은 종료 0이었다. 빌드 완료 뒤 공개 한국어·영어 홈·404 네 문서를 대조하여 일치를 확인했다. 처음 빌드와 출력 비교를 동시에 시작한 비교는 생성 중인 파일을 읽어 한 문서에서 불일치했으나, 빌드 완료 후 순차 비교는 네 문서 모두 일치했다. 제품 결함으로 판정하지 않는다.

원격 main·최종 보고서·push 배포 성공 SHA는 일치하며, 기존 브라우저 검사가 실행된 e427427과 최종 main 사이에는 화면·빌드 코드 변경이 없다. PDF는 8절·8쪽, 공개 증거 링크와 최종 SHA를 포함한다. 커밋 집계는 후보 104개·제외 2개·집계 102개이며 자동 분류가 모든 의미적 제외 조건을 판정하는 것은 아니다. LMS 최종 제출 완료 상태·다른 실제 기기/브라우저의 비공개 평가는 이번에 확인하지 않았다. 마감은 사용자 안내의 11월 7일을 적용하며 실제 LMS 마감 시각은 확인되지 않았다.
