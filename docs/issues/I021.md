## 공개 Git 작성자 정보

이는 사이트 본문·추적 텍스트/PDF 패턴 검색의 범위 밖인 Git 메타데이터다. 인증정보나 KONNECT 공격 경로를 발견했다는 의미는 아니다. 과제는 이름·연락처의 일괄 비공개를 강제하지 않으므로 확정 감점으로 판정하지 않되, 제출용 개인정보를 공개 범위에서 분리하려던 사용자 선택과 관련된 확인 사항이다. 기존 Git 이력 보존 규칙 때문에 작성자 정보의 소급 변경·이력 재작성·force push는 수행하지 않았다.

보완 시작 시 인증된 GitHub 계정의 ID와 로그인명으로 noreply 주소를 확인하고, 이 저장소에만 공개 활동명과 noreply 작성자·커미터 설정을 적용했다. 전역 설정은 변경하지 않는다. 이 설정은 이후 커밋에 적용되며 과거 공개 메타데이터까지 지운 것으로 표시하지 않는다. 과거 수정은 COMMIT_POLICY.md의 이력 재작성·force push 금지와 충돌하므로 별도 로컬 사본에서 변경 범위와 검증 결과를 준비한다.

## 최종 재검증 결과

요청한 innerWidth 완료와 글꼴·두 프레임 렌더를 기다린 뒤 두 언어·네 폭의 상세 검사 8개가 모두 통과했다. 새 공개 866b991에서 조작·화면 90개와 합계 98개, 점진적 향상 17개가 통과했다. JSON에 실제 배포 SHA·실행 작업 폴더 SHA·원본 시각을 구분해 보존한다. 메뉴 선택 변경·굵은 글씨·밑줄은 두 언어·네 폭 모두 확인했다. 새로운 화면 파일을 기존 evidence/T08에 저장한다.

로컬 pre-commit은 가상 예제의 잘못된 작성자와 커미터를 각각 차단했다. pre-push는 정상 교체 이력을 허용하고 개인정보가 남은 교체 전 로컬 검토 브랜치를 공개하려는 가상 입력을 차단했다. 실제 잘못된 이력을 원격에 push하지 않고 훅의 입력으로 검증했다. 원격 교체 당시 두 브랜치의 예상 SHA가 일치했으며 새 main·보관 브랜치·기준 커밋의 공개 API 정보도 대조했다.
