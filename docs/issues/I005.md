# I005 — 성공한 빌드에 소개 본문이 없음

- 상태: resolved
- 발견: 2026-10-29 KST, Claude 구현 후 첫 정적 HTML 검사.
- 재현: `python .github/pages_build.py --build` 후 `python scripts/check_site.py`.
- 실제: Hugo 빌드는 종료 코드 0이나 두 언어 모두 h1과 intro/about/future/current 앵커가 없다. 헤더·푸터만 출력된다. Hugo는 landing 페이지에 sections가 없다는 경고를 남긴다.
- 기대: 개인화한 main과 네 섹션이 두 언어 모두 출력되어야 한다.
- 원인 조사: 콘텐츠의 type은 landing인데 개인화는 일반 home.html에만 존재한다. 테마의 더 구체적인 landing/list.html이 우선 선택되는지 확인한다.
- 영향: 소개·활동·메뉴가 실질적으로 작동하지 않는다. 빌드 성공만으로 완료 처리할 수 없다.
- 근거: `docs/evidence/T08/static-first.json`.
- 수정: 개인화한 main 템플릿을 `site/layouts/landing/list.html`에 배치하여 테마의 동일 type 템플릿을 명시적으로 덮어썼다. HugoBlox baseof·head는 그대로 사용한다.
- 재검증: 두 언어 모두 h1 1개, 네 섹션·앵커, 이름·KONNECT 내용, 내부 링크와 자산 검사를 통과했다. `docs/evidence/T08/static-fixed.json` 참조.
- 참고: https://gohugo.io/templates/lookup-order/ 의 type·kind별 우선순위와 원본 `modules/blox/layouts/landing/list.html`을 대조했다.
