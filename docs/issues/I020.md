# I020 — 배운 점과 다음 개선의 연결 및 중간 결과 설명 보완

상태: 개선 전 관찰 기록. 2026-11-06 KST.

채점표 대조에서 공개 #current의 배운 점은 AI 제안을 직접 검증한다는 내용인데, 다음 문장은 완벽주의 조정만 제시해 P79의 ‘이에 연결되는 다음 개선 방향’이 명확하지 않았다. #future에는 사용자가 선택한 도움 요청 API의 정상·입력 오류·권한 오류 테스트 작성과 결과 정리 계획이 이미 있으므로 이를 배운 점과 직접 연결한다. 완료한 결과로 바꾸지 않는다.

P78의 공개 중간 문서는 인정 가능한 산출물이다. 다만 ‘적절한 오류 처리’ 등의 확인 관점과 실제 실행 결과가 혼동될 수 있다. 구현·테스트를 읽어 대조한 결과와 기존 검증 기록에 남은 회귀 검사·빌드·타입 검사 성공을 구분해 설명한다. 감점 확정이나 서비스 전체 검증 완료로 해석하지 않는다.

대상: site/layouts/landing/list.html의 두 언어 #current, docs/tasks/T03.md, docs/report-sections.json. 기존 레이아웃·폴더·학습 행동을 재사용한다. KONNECT 원본·로그·접속 경로·내부 판정 조건은 공개하지 않으며 이 작업에서 KONNECT 테스트를 새로 실행하지 않는다.

완료 조건: 두 언어의 배운 점과 다음 행동이 연결되고 공개 중간 기록의 확인 방법·결과·미실행 범위가 명확할 것. 빌드·본문 검사·주요 화면 폭에서 줄바꿈·정렬을 확인하고 최종 공개 버전과 로컬 제출 PDF를 맞출 것.
