# I019 — 공개 활동 설명의 내부 정책 상세 최소화

## 2026-11-07 추가 공개 개인정보 점검

학생은 적용 마감이 11월 7일 23:59임을 확인하고, 보고서의 개인정보를 유지하면서 공개 웹사이트의 개인정보를 정리하도록 요청하였음. 현재 사이트의 제목·본문·접근성 라벨·언어별 메타데이터·프로필에 영문 실명이 표시되고 있음을 확인하였음. 이 항목을 공개 식별자로 바꾸고 빌드 결과 전체에서 학번·실명·개인 이메일을 점검할 예정임.

이전 이력 교체 전 SHA가 GitHub에서 열리는 문제는 현재 배포 파일과 구분해 확인함. 현재 브랜치에서 접근이 끊긴 옛 객체·캐시는 일반 파일 수정으로 삭제할 수 없으므로 서버 측 제거 절차와 필요한 참조를 별도로 확인할 예정임. 개인정보 값 자체는 공개 이슈에 복사하지 않음.

상태: 현행 공개 내용 수정·재검증 완료. 2026-11-05 KST. 발견 기록: 046bc2b, 본문 수정: 6628008.

현재 활동 문서·두 언어 HTML·보고서 원문·AI 기록에서 불필요한 세부 정책을 줄였다. 이전 카드 그림은 현재 추적 파일에서 제외했고 JSON에는 작업 본문 대신 단계 수·검사 결과·좌표만 남긴다. 공개6628008에서 브라우저82개+상세/공개범위8개=90개와 점진적 향상17개가 통과했다. 두 언어 네 폭에서 정리 대상 문구가 없고 학습 행동·기록 링크·정렬이 유지되는 것을 확인했다. 텍스트·PDF 재검색에서도 실제 인증정보·운영 접속 경로는 발견하지 못했다. 과거 예제 접속 문자열은 예제값임을 분리해 판단했다. 최종 제출 PDF는 마지막 SHA로 다시 생성·검수한다.

사용자가 공개 내용에 공격 경로나 중요한 정보가 들어갔는지 확인·수정하도록 요청했다. 현재 추적 텍스트107개와 PDF9개, 도달 가능한 과거 텍스트·PDF blob993개를 검색하고 활동 문서·사이트·보고서를 읽어 대조했다. 실제 인증정보·운영 접속 주소·서비스 공격 절차는 확인하지 못했다. 과거 원본 테마의 로컬 DB 접속 예시는 예제 계정·예제 암호였다. 자동 패턴 검색은 모든 종류의 비밀을 검출한다는 보장이 아니며 앱 자체의 보안 검증이 아니다.

활동 문서에 정확한 입력 한도, 권한별 판정 조건과 응답의 대응, 내부 상태명·저장 처리 상세가 있다. 이를 공격 성공 경로로 판정한 것은 아니지만 공개 소개와 과제 증빙에 필요한 범위를 넘으므로 일반적인 처리·검증 방식으로 줄인다. HTML·활동 기록·보고서 원문·AI 기록·화면과 JSON 근거를 함께 확인한다. 내용이 들어간 이전 카드 전후 그림은 현재 추적 파일에서 제외하고 정렬 재검증 좌표는 유지한다.

개인 제출 정보는 기존대로 무시되는 로컬 최종 PDF에만 둔다. KONNECT 서비스에 접속·공격하지 않으며 원본 코드·설정도 변경하지 않는다. 이전 Git 커밋은 보존하므로 과거 문구까지 지웠다고 주장하지 않는다.

## 2026-11-07 원격 내용 재점검과 정리 대상

사용자의 재점검 요청에 따라 원격 두 브랜치를 확인하고 현재 추적 텍스트 97개·PDF 9개와 과거 텍스트/PDF를 패턴 검색하였음. 별도 KONNECT 작업 폴더의 텍스트 505개·코드 320개를 읽기 전용으로 대조하였으며, 원격 이력의 파일 1,150개와 커밋 메시지에서 원본 코드 파일·연속 8줄 코드·백엔드 정의 이름·민감값 일치를 찾지 못하였음. 과거 테마의 예제 접속 문자열은 KONNECT 정보와 구분하였음. 민감값·원본 코드·비공개 로그는 이 기록에 복사하지 않았음.

정리 과정에서 `site/config/_default/menus.yaml`은 주석만 있는 파일이고 실제 메뉴는 언어별 설정에서 관리함을 확인하였음. 초기 SVG 물결 화면 2장은 현재 구현에서 제거된 기능의 캡처이며, 현재 검사 결과에는 과거 캡처 시각만 남아 있었음. 프로필 주석의 과거 본문 위치와 출처 문서의 AI 사례 번호도 현재 경로·보고서와 달랐음. 이 상태를 먼저 기록하고 미사용 파일·캡처 목록과 설명을 정리한 뒤 빌드 출력을 대조할 예정임.
