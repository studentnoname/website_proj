# I024 — AI 사례의 본인 판단·직접 확인 근거 부족

## 2026-11-07 후속 발견 — 지속적인 본인 확인의 누락

학생은 사이트·PDF를 계속 직접 열어 확인하고 있는데, 보고서와 AI 기록의 ‘사용자 검토는 아직 받지 않았다’, ‘본인의 직접 실행으로 계산하지 않음’, ‘재생성한 PDF까지 본인이 확인한 것으로 소급하지 않음’ 등이 본인 확인을 부정하는 것으로 읽힌다고 지적하였음. 이미 제공된 노트북·아이폰, Chrome·Safari 확인과 가독성·모션 수정 판단을 현재 기록에 일관되게 반영하지 않은 문서 오류임.

현재 보고서의 3인칭 서술과 과거 기록의 시점이 명확하지 않은 부정문을 확인하였음. 본인 화면 확인은 본인 관점으로 기록하고 AI의 자동 측정·로그 생성은 보조 작업으로 구분할 예정임. 실제 수행하지 않은 개별 명령이나 새로운 KONNECT 실행 결과를 본인 실적으로 추가하지 않음.

발견일: 2026-11-07 KST. 상태: 본인 답변 대조·보고서 보완 및 PDF 검사 완료.

## 관찰과 재현

사용자가 전달한 평가 의견에서 보고서 세 사례의 반영 판단·동작 검증 주체가 Codex여서 P68·P70을 충족하지 못하였다고 지적하였음. 현재 `docs/report-sections.json`의 7절을 읽어 사례 1의 기술 검토, 사례 2의 빌드·화면·키보드 검사, 사례 3의 반영 판단·PDF 검수가 Codex 수행으로 기록된 것을 확인하였음. 실제 수행 주체의 표기는 유지해야 하지만 그 결과만으로 학생 본인의 판단·검증을 대신할 수 없음.

## 기대 결과와 영향

P68은 두 사례의 AI 응답과 본인의 채택·수정·보류 이유를, P70은 본인이 확인한 동작·예상·실제 결과·근거·범위를 요구함. 실제 대화의 학생 관찰·수정 요청과 AI가 수행한 기술 검사를 구분해야 함. 주체만 본인으로 바꾸거나 확인하지 않은 최종 결과를 통과로 쓰면 실제 기록과 다른 보고서가 됨.

## 보완 계획

기존 대화에서 본문 크기·배치·강조가 불균일하다는 관찰 및 재제작 판단, 효과를 켜니 보인다는 확인 및 불투명도·흐름 개선 판단을 각 사례에 연결함. 확인 시점은 당시 초안이며 기기·브라우저·정확한 시각은 확인되지 않았음을 명시함. 현재 공개본의 본인 재확인 결과는 별도로 요청하였으며 답변 없이 완료로 기록하지 않음. Codex의 빌드·자동 검사·PDF 검수는 보조 근거로 유지함.

## 본인 답변과 수정

발견 기록 `0c8c2c2` 이후 두 차례 답변을 받았음. 학생은 노트북·아이폰과 Chrome·Safari에서 직접 확인하였다고 밝혔음. 웹사이트의 띄어쓰기·문자 크기를 보기 쉽게 수정한 판단, 모션 위치 문제를 특정 위치 지시로 바로잡고 불투명도를 명시해 해결한 결과, PDF의 종결어미·크기·글꼴을 조정해 내용·목차를 구분한 판단을 설명하였음.

보고서 7절의 세 사례에 각각 본인의 예상·관찰·채택/수정/보류 이유·후속 확인을 구분하고 `docs/ai/usage.md`의 U01·U02·U03 확인표에 대화 원문을 보존하였음. 확인표는 제출 SHA에 고정된 클릭 링크로 연결함. 정확한 실행 시각·브라우저 버전·기기별 측정값은 답변에 없어 만들지 않았음. 5·6절의 기존 기술 진단·캡처·자동 검사는 Codex 수행으로 명시하였음.
