# I024 — AI 사례의 본인 판단·직접 확인 근거 부족

발견일: 2026-11-07 KST. 상태: 보완 중.

## 관찰과 재현

사용자가 전달한 평가 의견에서 보고서 세 사례의 반영 판단·동작 검증 주체가 Codex여서 P68·P70을 충족하지 못하였다고 지적하였음. 현재 `docs/report-sections.json`의 7절을 읽어 사례 1의 기술 검토, 사례 2의 빌드·화면·키보드 검사, 사례 3의 반영 판단·PDF 검수가 Codex 수행으로 기록된 것을 확인하였음. 실제 수행 주체의 표기는 유지해야 하지만 그 결과만으로 학생 본인의 판단·검증을 대신할 수 없음.

## 기대 결과와 영향

P68은 두 사례의 AI 응답과 본인의 채택·수정·보류 이유를, P70은 본인이 확인한 동작·예상·실제 결과·근거·범위를 요구함. 실제 대화의 학생 관찰·수정 요청과 AI가 수행한 기술 검사를 구분해야 함. 주체만 본인으로 바꾸거나 확인하지 않은 최종 결과를 통과로 쓰면 실제 기록과 다른 보고서가 됨.

## 보완 계획

기존 대화에서 본문 크기·배치·강조가 불균일하다는 관찰 및 재제작 판단, 효과를 켜니 보인다는 확인 및 불투명도·흐름 개선 판단을 각 사례에 연결함. 확인 시점은 당시 초안이며 기기·브라우저·정확한 시각은 확인되지 않았음을 명시함. 현재 공개본의 본인 재확인 결과는 별도로 요청하였으며 답변 없이 완료로 기록하지 않음. Codex의 빌드·자동 검사·PDF 검수는 보조 근거로 유지함.
