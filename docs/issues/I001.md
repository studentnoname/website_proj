# I001 — 테마 원본의 docs 제외 규칙이 과제 기록을 숨김

- 상태: resolved
- 발견: 2026-10-29 KST, T01 기록 stage 중.
- 재현: `git check-ignore -v docs/README.md`.
- 실제: 원본 `.gitignore`의 `/docs/` 규칙 때문에 새 작업 기록이 기본 stage에서 제외된다.
- 기대: 과제 기록은 추적하고 원본 빌드 문서용 제외 규칙과 구분한다.
- 영향: 검증·오류·커밋 집계 근거가 원격 저장소에 누락될 수 있다.
- 임시 대응: 첫 인계 기록만 경로를 지정해 `git add -f`로 보존했다.
- 다음 조치: 과제 docs에 대한 명시적인 포함 규칙을 추가하고 기본 stage로 추적됨을 확인한다.
- 수정: `.gitignore` 끝에 `!/docs/`, `!/docs/**`를 추가했다.
- 재검증: `git check-ignore docs/README.md`가 무시 규칙을 반환하지 않고 새 문서가 일반 `git add`에 포함됨을 확인했다.
