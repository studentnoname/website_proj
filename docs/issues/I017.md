# I017 — 보고서의 검증 근거 일부가 공개 저장소 경로로 연결되지 않음

상태: 확인·수정 전. 2026-11-05 KST.

최종 보고서 5~6쪽은 `submission/screens/results.json`, ‘Firefox 결과 JSON’, `keyboard-focus.png` 같은 경로 또는 파일명을 근거로 기재한다. submission은 개인정보 보호를 위해 Git에서 제외되므로 PDF만 받은 채점자가 해당 로그를 열 수 없다. 화면은 PDF에 포함되어 있지만 그림별 저장소 상대 경로도 명시되지 않았다. 보고서의 5영역 관찰 자체는 존재하며, 문제는 근거의 식별·접근성이다.

수정 방향: 공개 배포를 검사한 JSON과 대표 그림을 기존 `docs/evidence/T08/` 경로에 보존한다. 보고서에 그림 번호·정확한 저장소 상대 경로·클릭 가능한 저장소 링크를 연결하고, 시각·URL·폭을 유지한다. 학생 식별 정보와 최종 PDF는 계속 로컬 submission에만 둔다. 마감은 사용자 확인에 따라 2026-11-07이며 종료 시각은 LMS 공지를 따른다.
