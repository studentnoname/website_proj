# I016 — 404 화면의 메뉴가 없는 현재 페이지 앵커를 가리킴

상태: 해결됨·공개 재검증 완료. 2026-11-05 KST. 수정 전 기록: `ed8514f`, 경로 수정: `97df370`.

공개 후속 검증: 1440·390px 두 언어의 메뉴/로고 복구 20개와 실제 없는 공개 주소의 메뉴 복구를 포함한 82개 검사가 통과했다. `../evidence/T08/firefox/results.json`의 error-…-recovers와 missing-route-menu-recovers, error-1440/390-ko/en-about.png에서 목적지·화면을 확인할 수 있다. 이후 소개 문구 전용 4개 검사를 합친 최종 브라우저 근거는 86개다. 아래 배포 전 계획·로컬 기록과 구분한다.

공개 주소 `/website_proj/not-a-real-audit-page/`에서 ‘그는 누구인가’를 누르면 URL만 같은 오류 주소의 `#about`으로 바뀌고 404 화면에 남는다. 해당 문서에는 about 대상이 0개다. 로고로 홈 복귀는 가능하다. 영어 404 출력에도 같은 형태의 fragment-only 메뉴가 있다. 비공개 잘못된 주소 검사와 메뉴 도착 위치에서 감점 위험이 있다.

원인은 일반 홈과 404에서 공유하는 원본 메뉴의 `#intro`, `#about`, `#future`, `#current`가 오류 문서 기준으로 해석되는 것이다. 기존 운영 출력 경로 보정에서 404에 한해 같은 언어의 홈 경로를 붙이고, 정상 홈의 앵커·모션·배치를 유지한다. 실제 정적 검사와 404 상태의 메뉴 클릭·홈 복귀·양 언어·모바일로 재검증한다.

수정 전 실제 결과와 화면: `../evidence/T08/404-before.json`, `../evidence/T08/firefox/404-before.png`.

기존 운영 출력 보정의 resolve()에서 404의 네 홈 앵커만 같은 언어의 홈 경로로 바꿨다. 준비 스크립트 사본도 같은 동작을 유지한다. 새 프론트 템플릿·폴더를 만들지 않았다. 정적 검사는 한국어·영어 홈뿐 아니라 두 404도 포함하도록 확장했고 모두 오류 0이다. Firefox 검사는 1440·390px에서 두 언어의 메뉴 네 개 및 홈 로고 복귀 20개를 추가하여 로컬 총 81개가 통과했다. 실제 존재하지 않는 주소의 공개 복구는 배포 후 별도로 확인한다.
