# I016 — 404 화면의 메뉴가 없는 현재 페이지 앵커를 가리킴

상태: 재현·수정 전. 2026-11-05 KST.

공개 주소 `/website_proj/not-a-real-audit-page/`에서 ‘그는 누구인가’를 누르면 URL만 같은 오류 주소의 `#about`으로 바뀌고 404 화면에 남는다. 해당 문서에는 about 대상이 0개다. 로고로 홈 복귀는 가능하다. 영어 404 출력에도 같은 형태의 fragment-only 메뉴가 있다. 비공개 잘못된 주소 검사와 메뉴 도착 위치에서 감점 위험이 있다.

원인은 일반 홈과 404에서 공유하는 원본 메뉴의 `#intro`, `#about`, `#future`, `#current`가 오류 문서 기준으로 해석되는 것이다. 기존 운영 출력 경로 보정에서 404에 한해 같은 언어의 홈 경로를 붙이고, 정상 홈의 앵커·모션·배치를 유지한다. 실제 정적 검사와 404 상태의 메뉴 클릭·홈 복귀·양 언어·모바일로 재검증한다.
