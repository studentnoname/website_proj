# I023 — 현재 원문과 TASK PDF의 버전 차이

발견일: 2026-11-06 KST. 상태: 수정·원문 대조·전체 렌더 검증 완료.

## 관찰과 영향

전체 파일·PDF 대조에서 `docs/tasks/T03.pdf`는 1쪽의 과거 ‘KONNECT 활동’ 기록으로, ‘공개 산출물 없음’ 및 P78 증빙 부족 설명이 남아 있었음. 현재 `T03.md`는 11월 5~6일의 공개 중간 작업 기록이며 구현 읽기 대조·기존 실행 결과·다음 학습 행동을 구분하고 있음. `T09.pdf`도 현재 원문과 달리 학습 행동·구체적 적용·중간 결과의 공백을 현재 상태처럼 기술하였음.

현재 PDF 9개를 모두 텍스트로 추출해 확인하였음. T03·T09의 위 문장은 더 이상 현재 상태를 설명하지 않으므로 PDF를 함께 제출하면 원문·보고서와 판단 근거가 달라질 수 있음. 과거 오류·미실행 기록 자체를 삭제해야 한다는 뜻은 아님.

## 기대 결과와 수정 계획

최신 TASK 원문으로 PDF 9개를 다시 생성하고, 날짜별 경과와 현재 상태를 명확하게 구분함. 필수 AI 요청 원문·판단·검증 범위, 오류의 관찰·수정·재검증, 라이선스는 보존함. 제목·소제목·본문의 서체·크기·문단 간격을 구분하고 모든 페이지를 렌더해 확인할 예정임.

## 수정과 재검증

발견 기록 5c70950을 남긴 뒤 원문과 PDF를 동기화하였음. 원인은 원문 보완 후 이전에 생성한 TASK PDF가 갱신되지 않은 상태였음. 현재 T03은 2쪽의 백엔드 중간 기록이며 구현 읽기 대조·2026-11-04 기존 실행 기록·향후 학습 행동을 구분함. T09는 4쪽으로 갱신하고 직전 측정값과 현재 형식을 명시하였음.

TASK PDF 9개 15쪽의 모든 원문 문단·표 셀·흐름 단계가 PDF 텍스트에 포함된 것을 대조하였음. 제출 보고서는 12쪽·필수 8절·대표 AI 사례 3건·링크 주석 42개와 고유 URL 27개를 확인하였음. 보고서에서 생략한 초기 계획 사례의 실제 요청은 기존 AI 기록과 계획서에 보존하였고, 남은 실제 요청·URL·표·그림은 변경하지 않았음.

바탕 계열 24pt·16pt, 고딕 굵은체 12pt와 고딕 본문 10.5pt를 적용하였음. 총 27쪽을 렌더해 글·표·그림·쪽번호·줄바꿈을 확인하였고 본문 영역의 여백·문자 누락·넘침을 검사하였음. 새 브라우저·KONNECT 실행 결과로 표시하지 않았음. 최종 SHA·Actions 링크는 main push 성공 뒤 제출 PDF 내보내기에서 확정함.
