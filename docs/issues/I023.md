# I023 — 현재 원문과 TASK PDF의 버전 차이

발견일: 2026-11-06 KST. 상태: 재현 확인, 수정 전 기록.

## 관찰과 영향

전체 파일·PDF 대조에서 `docs/tasks/T03.pdf`는 1쪽의 과거 ‘KONNECT 활동’ 기록으로, ‘공개 산출물 없음’ 및 P78 증빙 부족 설명이 남아 있었음. 현재 `T03.md`는 11월 5~6일의 공개 중간 작업 기록이며 구현 읽기 대조·기존 실행 결과·다음 학습 행동을 구분하고 있음. `T09.pdf`도 현재 원문과 달리 학습 행동·구체적 적용·중간 결과의 공백을 현재 상태처럼 기술하였음.

현재 PDF 9개를 모두 텍스트로 추출해 확인하였음. T03·T09의 위 문장은 더 이상 현재 상태를 설명하지 않으므로 PDF를 함께 제출하면 원문·보고서와 판단 근거가 달라질 수 있음. 과거 오류·미실행 기록 자체를 삭제해야 한다는 뜻은 아님.

## 기대 결과와 수정 계획

최신 TASK 원문으로 PDF 9개를 다시 생성하고, 날짜별 경과와 현재 상태를 명확하게 구분함. 필수 AI 요청 원문·판단·검증 범위, 오류의 관찰·수정·재검증, 라이선스는 보존함. 제목·소제목·본문의 서체·크기·문단 간격을 구분하고 모든 페이지를 렌더해 확인할 예정임.
