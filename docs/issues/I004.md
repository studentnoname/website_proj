# I004 — Firefox headless WebDriver 세션 시작 실패

- 상태: investigating
- 발견: 2026-10-29 KST, 원본 화면 캡처용 Firefox 검사 준비.
- 환경: Firefox 158.0.1, geckodriver 0.37.1, Selenium, Windows.
- 재현: 프로젝트 전용 임시 프로필로 `webdriver.Firefox()`를 headless 실행한다.
- 실제: Marionette 연결 전에 Firefox 프로세스가 상태 0으로 종료되어 Selenium 세션이 만들어지지 않는다.
- 기대: 로그인·사용자 기본 프로필과 무관한 검사 프로필로 페이지를 열 수 있어야 한다.
- 영향: 이 시도에서는 Firefox 화면·키보드 검사 근거를 확보하지 못했다. 사이트 자체의 실패로 판단하지 않는다.
- 다음 조치: 독립 프로필의 Firefox 직접 캡처와 실행 경로를 확인하고 필요하면 다른 Firefox 실행 패키지로 교차 점검한다.
