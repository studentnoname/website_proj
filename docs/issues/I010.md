# I010 — 물결 효과 상태 문구에 따옴표가 표시됨

상태: 발견, 수정 전 기록. 2026-11-04 KST.

## 관찰과 재현

스크롤 물결 구현 후 Hugo 빌드와 Firefox 기능 검사 45건은 통과했다. 전체 화면을 직접 확인하면서 하단 효과 버튼의 켜짐 상태가 `"켜짐"` / `"On"`처럼 따옴표를 포함하는 것을 발견했다. `public/index.html`에는 `data-on='"켜짐"'`, 영어에는 `data-on='"On"'`이 출력됐다. 원본 템플릿 값은 일반 문자열이다.

## 기대 결과와 영향

화면 상태 문구는 따옴표 없이 `켜짐` 또는 `On`이어야 한다. 효과 실행·중지와 aria-pressed 동작은 정상이나 표시 문구가 의도와 다르다. 기능 검사 통과만으로 시각 검수를 대신할 수 없다.

## 원인 판단과 수정 계획

Hugo HTML 템플릿이 `data-on`을 JavaScript 이벤트 속성과 같은 문맥으로 처리하여 문자열을 JSON 인용 형태로 출력한 것으로 판단했다. 값 우회나 HTML 안전성 강제 처리 대신 이벤트 이름과 겹치지 않는 데이터 속성으로 바꾸고 두 언어에서 실제 출력·화면·토글 동작을 재검증한다.
