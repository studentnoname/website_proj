# I009 — 보고서의 실제 제외 커밋 상세 누락

상태: 발견, 수정 전 기록. 2026-11-04 KST.

## 관찰과 재현

main `22fca6a3d22dc00d3616662df4714972707a2805`에서 공개 검사 후 `scripts/collect_release.py`, `scripts/render_records.py --release ... --identity ...`로 보고서를 생성했다. 보고서 4절은 후보 71개·제외 2개·유효 69개와 일반 제외 규칙을 적었으나, 실제 제외 대상 두 건의 SHA·개별 이유를 모두 적지 않았다. `submission/release.json`에는 상세 정보가 있지만 LMS 제출물은 PDF 한 개다.

## 기대 결과와 영향

원본 공개 채점기준 10쪽의 집계 근거에 맞춰 PDF 안에서 실제 제외 SHA 또는 범위·유형·이유를 확인할 수 있어야 한다. 현재 PDF는 기본 원본 등록 SHA만 설명하고 PDF 자동 생성 커밋의 SHA를 누락하여 상세 근거가 외부 로컬 파일에 의존한다.

## 원인 판단

`docs/report-sections.json`의 4절에 일반 제외 규칙과 JSON 보존 위치만 적고, 실제 제외 목록을 넣지 않았다. 집계 알고리즘의 수치 오류는 관찰하지 않았다.

## 수정 전 근거

제외 대상은 `42f92735f3729f9aa0d63d637fa45f6d2dd25629`(원본 ZIP·준비 결과 단순 등록)와 `da55e5d64189339685ec56c9ca729d7a34ee0ecb`(TASK PDF만 자동 생성)다. 개인정보가 있는 제출 PDF는 공개 Git에 넣지 않는다.
