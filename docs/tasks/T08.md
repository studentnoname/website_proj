# T08 — 검증과 개선

상태: 정적 검사와 로컬 Firefox 검사 완료, 최종 공개 배포 검증은 별도 기록.

## 검증 방식

`scripts/check_site.py`는 두 언어의 제목·섹션·HTML lang·로컬 자산·빈 링크·직접 앵커를 검사한다. `scripts/browser_qa.py`는 실제 Firefox 159.0에서 20개 배치·메뉴·언어·키보드·확대·움직임 동작을 검사한다.

## 실제 문제 해결

I001 기록 제외, I002 npm 격리, I003 불필요한 upstream 봇 설정, I004 Firefox 시작, I005 본문 미출력, I006 데모 출력 잔존, I007 검사 도구의 잘못된 전제, I008 헤더 가독성을 각각 발견·수정·재확인했다.

## 변경 전후

변경 1: 일반 홈 override가 선택되지 않아 본문·앵커가 없었음 → landing/list override로 두 언어의 네 섹션 출력. 변경 2: 데모 콘텐츠 삭제 후에도 오래된 출력이 남았음 → cleanDestinationDir 및 데모 자산 제거로 현재 자료만 출력. 추가 개선: 반투명 헤더 → 불투명 헤더.

## 근거와 한계

`docs/issues/`, `docs/evidence/T08/`, `docs/verification.md`에 예상·실제·URL·시각·화면을 연결한다. 로컬 검사와 공개 사이트 검사를 구분하며 일부 콘텐츠 미기재를 기능 통과로 대신하지 않는다.
