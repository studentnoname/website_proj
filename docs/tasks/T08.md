# T08 — 검증과 개선

상태: 정적 검사와 공개 Firefox 검사 완료. 실행 시각·검사 버전·기준 SHA는 `docs/evidence/T08/`의 JSON에 보존하였음.

## 검증 방식

직접 확인: 노트북·아이폰과 Chrome·Safari에서 사이트를 계속 열어 본문 크기·띄어쓰기·배치·강조를 확인하였음. 스크롤 모션은 예상한 위치와 실제 위치를 비교해 수정을 요청하고, 다시 열어 위치 문제의 해결과 불투명도 보완 결과를 확인하였음. PDF도 직접 읽어 종결어미·글자 크기·글꼴·문단과 목차의 구분을 확인하였음. 실제 관찰과 수정 이유는 `docs/ai/usage.md`의 U01~U03에 보존하였음.

아래 스크립트·Firefox 측정값·캡처는 직접 화면 확인에 더해 활용한 자동 검사 자료임.

`scripts/check_site.py`로 두 언어 홈·404의 제목·섹션·HTML lang·로컬 자산·빈 링크·직접 앵커를 검사하였음.

공개 Firefox 159.0.1에서 화면·조작 90개와 상세 배치 8개, 합계 98개 및 점진적 향상 17개 검사를 통과하였음. 메뉴·언어·키보드·확대·화면 전환과 두 언어·네 폭의 현재 항목 표시를 확인하였음. 결과는 `docs/evidence/T08/firefox/results.json`, `docs/evidence/T08/progressive/results.json` 및 `docs/verification.md`에 연결하였음.
