# T04 — 메뉴와 링크

상태: 구현·로컬 조작 검증 완료.

## 404 메뉴 복구 — 2026-11-05 KST

채점 점검에서 오류 주소의 메뉴가 없는 현재 문서 앵커를 가리키는 것을 재현했다(I016). 기존 빌드 경로 보정에서 두 404만 같은 언어의 홈 주소를 붙이도록 수정했다. 기존 홈 메뉴·배치·효과는 유지한다. 한국어·영어 404의 네 메뉴와 로고를 1440·390px에서 확인했고 로컬 81개 검사가 통과했다. 정적 검사도 홈과 404 네 문서를 포함한다.

## 요구사항과 선택

요청된 메뉴 원문을 유지하고 네 실제 앵커를 연결했다. 기본 링크는 JavaScript 없이도 작동하는 네이티브 앵커다. 본인 GitHub 링크는 제출 저장소로 연결했다.

## 변경과 파일

`site/config/_default/menus.ko.yaml`, `menus.en.yaml`에 메뉴를 정의하고 `site/layouts/_partials/components/headers/navbar.html`에서 출력한다. footer의 처음 복귀 링크, 언어 전환 링크를 제공한다. `scripts/serve.py`는 실제 `/website_proj/` 경로를 재현한다.

## 실제 검증

메뉴 선택, `#about` 직접 URL·새로고침, `#current` 이동 후 뒤로 가기, 같은 섹션을 유지하는 언어 전환을 Firefox에서 확인했다. 정적 검사로 내부 링크·앵커·자산 경로와 빈 링크 부재를 확인했다.

## 한계와 관련 이력

활동 산출물 링크는 사용자가 제공하지 않아 추가하지 않았다. 기존 hub는 본인 활동 관계가 미확인이라 연결하지 않았다. 관련 커밋: `e2f3d18`, `53c604c`, `9eb2024`, `30d1161`. I005의 누락 앵커는 템플릿 수정으로 해결했다.
