# T02 — 소개와 학습 방향

상태: 화면 구현·로컬 검증 완료, 일부 콘텐츠는 사용자 요청으로 미기재.

## 요구사항과 선택

이름과 실제 관심 이유를 짧은 글과 SVG 흐름 그림으로 표현한다. 이미지에만 정보를 넣지 않고 h1·h2와 읽을 수 있는 본문을 유지했다.

## 변경과 파일

`site/data/portfolio/ko.yaml`, `en.yaml`에 이름·AI 병목 경험·도구·학습 방향을 작성했다. `site/layouts/_partials/portfolio/intro.html`, `about.html`, `future.html`이 이를 표시한다. 원본 가상 인물·기관·학력·논문은 사이트 콘텐츠에서 제거했다.

## 실제 검증

두 언어에 h1 1개와 네 섹션이 출력되고 1440·768·390px에서 가로 넘침이 없음을 Firefox 159.0으로 확인했다. 정적 결과는 `docs/evidence/T08/static-final.json`, 화면은 `docs/evidence/T08/firefox/`.

## 한계와 관련 이력

구체적인 다음 학습 행동은 사용자의 “빈칸으로 두기” 요청에 따라 만들지 않았다(P72). 도구와 특정 구현 기능의 대응도 미확인이다(P73). 관련 커밋: `477c0b4`, `8919f2b`, `13eacab`, `b41cfdf`, `d1a3e53`. I005 수정 후 본문 출력을 확인했다.
