# T06 — 다국어와 반응형 조작

상태: 두 언어·메뉴·키보드·폭·확대 로컬 검사 통과.

## 스크롤 물결 추가 — 2026-11-04 KST

사용자 요청 “웹사이트 스크롤 하면서 애니매이션을 추가 물이 흐르는 것처럼”에 따라 기존 세 프론트 파일에 물결 두 곳과 하단 효과 버튼을 추가했다. Claude Code가 구현하고 Codex가 검토했다. 본문 크기·정렬·기존 내용은 유지하며 native scroll을 변경하지 않는다. 스크롤 위치에 따라 SVG 경로가 바뀌고 정지 후 최대 약 600ms 안에 가라앉는다. 화면 밖·비활성 탭·효과 끄기·모션 축소 조건에서는 지속 프레임을 예약하지 않는다.

I010의 상태 문구 따옴표 문제를 시각 검토에서 발견해 먼저 기록·커밋하고 데이터 속성 이름을 수정했다. 두 언어 상태 문구, PC·모바일의 실제 스크롤 경로 변화, 정지 후 400ms 프레임 예약 0, 키보드 끄기·켜기, 실행 중 모션 축소 전환을 기존 검사에 추가했다. 실제 결과는 `docs/evidence/T08/`과 `docs/verification.md`에 보존한다.

## 요구사항과 선택

한국어를 루트에, 영어를 `/en/`에 둔다. 모바일 메뉴는 점진적 향상으로 제공하고 같은 섹션으로 언어를 바꿀 수 있게 했다. 움직임은 줄일 수 있으며 본문은 스크립트 실행을 기다리며 숨겨지지 않는다.

## 변경과 파일

언어별 content와 메뉴·portfolio 데이터, HTML lang을 설정했다. `site/assets/js/portfolio.js`가 메뉴의 열림·닫기·Escape·초점 복귀·폭 변경 복구·언어 앵커·움직임 선택을 처리한다. CSS는 작은 화면과 reduced-motion 조건을 처리한다.

## 실제 검증

Firefox 159.0에서 두 언어 1440·768·390px, 메뉴 선택·Escape·폭 왕복 변경·언어 전환·키보드·실제 200%를 확인했다. 390px는 실제 innerWidth로 검증했다. 확대는 DPR 1→2, 콘텐츠 폭 1440→720으로 확인했다.

## 한계와 관련 근거

Windows 브라우저 기기 크기 검사를 실제 iPhone 검사라고 표시하지 않는다. 결과는 `docs/evidence/T08/firefox/results.json`. 초기 검사 도구의 폭·확대 오판은 I007로 기록·수정했다. 주요 커밋: `d28ff11`, `91700fb`, `f034550`, `817632f`.
