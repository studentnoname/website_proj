# T06 — 다국어와 반응형 조작

상태: 두 언어·메뉴·키보드·폭·확대 로컬 검사 통과.

## 불투명도와 물처럼 가라앉는 전환 — 2026-11-04 KST

사용자는 효과를 켜니 잘 보인다고 확인하고 불투명도·자연스러움을 추가 요청하였음. Claude Code가 기존 CSS·JS만 다듬었다. 들어오는 패널 전체의 불투명도는 0.88부터 시작해 덮기 75%에서 1로 복원됨. 하나의 넓은 곡선과 최대 PC 24px·모바일 14px의 짧은 추종 움직임을 적용하였음. 마지막 스크롤 후 320ms 안에 이동이 정확히 0으로 가라앉으며 정지 중 반복 프레임은 없음. 첫 글 등장은 900ms·120ms 간격임. 기존 글자 크기·내용·배치·메뉴·모션 제어는 유지함. 실제 브라우저에서 양방향 잔여 이동·불투명도·완전 정지·키보드를 검증함.

실제 검증은 Firefox 61개와 점진적 향상 17개가 통과하였음. 새 추종 검사의 첫 프레임 표본 문제는 I015에 수정 전·후를 보존했고 앱을 바꿔 검사 결과에 맞추지 않았음. 효과 끄기에서는 이동·투명도·clip이 모두 초기화되었음.

## 첫 화면 주소와 즉시 재생 링크 — 2026-11-04 KST

I014에서 #intro 접속이 첫 화면의 등장을 생략하는 것을 재현하고 수정하였음. 명시적 `?motion=on` 링크는 효과를 켜고 해당 매개변수만 history에서 소비함. 끈 뒤 새로고침해도 꺼진 선택을 유지함. 본문 직접 링크는 즉시 읽을 수 있고 일반 주소는 기존 시스템 모션 축소 설정을 따름. 한국어·영어의 첫 접속·#intro 새로고침·끄기 유지 조건을 추가하여 점진적 향상 검사는 17개다.

## 기본 설정에서 효과가 안 보이는 문제 — 2026-11-04 KST

사용자의 “동일한데 변한게 없어” 이후 강제 모션 설정을 제거한 Firefox에서 실제 reduced=true·효과 off를 확인했다(I013). 기존 하단 버튼이 시스템 모션 축소 때 켜기를 막던 문제를 수정하였음. 첫 화면에도 같은 버튼을 제공하고 사용자의 명시적 선택을 허용함. 초기 상태는 시스템을 따르며 시스템 설정을 직접 바꾸지 않음. 켜기 즉시 첫 화면을 850ms·120ms 간격으로 재생하며 두 제어의 상태가 동기화됨. 기존 55개와 확장한 점진적 향상 11개 검사가 통과하였음.

## 화면 덮기 방식 도입 — 2026-11-04 KST

물결 장식은 사용자 설명에 따라 제거하였음. 이 도입 단계에서는 제목·소개가 80ms 간격으로 들어오도록 하였고, 이후 위의 불투명도 조정 단계에서 900ms·120ms 간격으로 갱신하였음. 기존 섹션의 배경과 내용 전체가 다음 섹션 아래에 가려지는 방식을 적용하였음.

앵커는 일반 흐름의 section에, 고정·곡선 clip은 내부 패널에 적용해 직접 주소를 보존함. 긴 내용은 먼저 끝까지 스크롤하며, 하단 화면 효과 버튼·모션 축소·JS 비활성에서는 일반 문서 흐름을 이용함.

Claude Code가 기존 HTML·CSS·JS 세 파일을 구현하였음. Codex가 빌드와 실제 화면을 확인하고 I011의 검사 전제를 수정하였음. 실제 겹침·곡선 변화·글의 등장 시각·정지 시 프레임·키보드·직접 주소를 포함한 55개 검사와 별도 2개 검사가 통과하였음. 아래 물결 장식은 이전 시도 기록이며 현재 구현이 아님.

## 스크롤 물결 추가 — 2026-11-04 KST

사용자 요청 “웹사이트 스크롤 하면서 애니매이션을 추가 물이 흐르는 것처럼”에 따라 기존 세 프론트 파일에 물결 두 곳과 하단 효과 버튼을 추가하였음. Claude Code가 구현하고 Codex가 검토하였음. 본문 크기·정렬·기존 내용은 유지하며 native scroll을 변경하지 않음. 스크롤 위치에 따라 SVG 경로가 바뀌고 정지 후 최대 약 600ms 안에 가라앉는다. 화면 밖·비활성 탭·효과 끄기·모션 축소 조건에서는 지속 프레임을 예약하지 않음.

I010의 상태 문구 따옴표 문제를 시각 검토에서 발견해 먼저 기록·커밋하고 데이터 속성 이름을 수정하였음. 두 언어 상태 문구, PC·모바일의 실제 스크롤 경로 변화, 정지 후 400ms 프레임 예약 0, 키보드 끄기·켜기, 실행 중 모션 축소 전환을 기존 검사에 추가하였음. 실제 결과는 `docs/evidence/T08/`과 `docs/verification.md`에 보존함.

## 요구사항과 선택

한국어를 루트에, 영어를 `/en/`에 둔다. 모바일 메뉴는 점진적 향상으로 제공하고 같은 섹션으로 언어를 바꿀 수 있게 하였음. 움직임은 줄일 수 있으며 본문은 스크립트 실행을 기다리며 숨겨지지 않음.

## 변경과 파일

언어별 content와 메뉴·portfolio 데이터, HTML lang을 설정하였음. `site/assets/js/portfolio.js`가 메뉴의 열림·닫기·Escape·초점 복귀·폭 변경 복구·언어 앵커·움직임 선택을 처리함. CSS는 작은 화면과 reduced-motion 조건을 처리함.

## 초기 조작 검증 — 2026-10-29

Firefox 159.0에서 두 언어 1440·768·390px, 메뉴 선택·Escape·폭 왕복 변경·언어 전환·키보드·실제 200%를 확인하였음. 390px는 실제 innerWidth로 검증하였음. 확대는 DPR 1→2, 콘텐츠 폭 1440→720으로 확인하였음.

## 한계와 관련 근거

Windows 브라우저 기기 크기 검사를 실제 iPhone 검사라고 표시하지 않음. 결과는 `docs/evidence/T08/firefox/results.json`. 초기 검사 도구의 폭·확대 오판은 I007로 기록·수정하였음. 주요 커밋: `8a1aa5c`, `e9e734d`, `30d1161`, `79d8b23`.
