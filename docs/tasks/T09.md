# T09 — 이력과 제출 보고서

상태: 재현 문서·기록 체계 구현, 최종 버전의 로컬 PDF 내보내기 단계.

## 공개 정보 최소화 — 2026-11-05 I019

사용자의 보안·민감정보 확인 요청에 따라 현재 공개 텍스트·PDF와 과거 텍스트/PDF를 검색하고 문서 내용을 검토했다. 실제 운영 인증정보·접속 경로·공격 절차는 확인하지 못했으나 불필요한 내부 정책 상세를 사이트·활동 기록·보고서·AI 기록에서 줄인다. 이전 본문이 복사된 JSON과 이전 카드 그림도 현재 공개 범위에서 제외하고 새 화면·검사 결과로 갱신한다. 과제의 실제 작업 설명·중간 기록·선택한 학습 행동과 제출용 필수 개인정보는 유지한다. 과거 Git 커밋은 보존한다.

## 설명 구체화·학습 행동·중간 기록 — 2026-11-05 후속 요청

공개9b49287에서 브라우저82개+콘텐츠8개=90개와 점진적 향상17개를 재검증했다. 기록 링크200·문서 내용, 선택한 학습 행동, 네 단계 설명, 카드 정렬을 확인했다. 마지막 근거 커밋은 프론트 코드를 바꾸지 않으며 최종 배포·SHA에 맞춰 제출 PDF를 내보낸다.

선택된 도움 API 정상·입력 오류·권한 오류 테스트 작성 계획을 P72로 연결하고, 실제 입력 검증·권한·저장·상태 처리 방법을 네 단계로 설명한다. P78에는 원본 코드를 복사하지 않은 docs/tasks/T03.md의 구현 대조·기존 검증 요약 기록을 공개 화면에서 연결한다. 보고서도 해당 위치·내용·미실행 범위를 갱신한다. 아래 ‘공백’ 관련 이전 점검과 구분한다.

## 검증 근거의 저장소 연결 — 2026-11-05 KST

공개 기능82개·마지막 소개 문구4개와 점진적 향상17개를 실제 확인해 같은 근거 경로에 보존했다. 그림별 파일 시각을 기록해 캡션에 사용하며 검사 묶음의 SHA도 구분한다. 비공개 KONNECT 코드를 읽어 실제 작업 범주를 보완했으나 공개 산출물 증빙이나 이번 실행 검증으로 대신하지 않는다.

보고서의 로컬 submission 경로·불완전한 파일명을 I017에 기록했다. 본문 검증표는 E1~E4로 실제 추적 파일을 연결하고, 링크는 제출 SHA에 고정한다. 그림 1~3도 기존 docs/evidence/T08/firefox 파일을 이용하며 정확한 상대 경로를 표시하고 클릭할 수 있게 한다. 검사 개수와 캡처 시각은 추적되는 JSON에서 읽는다. 공개 검증 후 그 실제 결과를 같은 경로에 보존한다. 학생 정보와 최종 PDF는 계속 로컬에 둔다.

## 요구사항과 선택

제공 보고서 1~8절에 제출 정보·환경·기능 변경 2건·Git 집계·5영역 검증·문제 해결·실제 AI 사례 2건·출처를 담는다. 개인정보는 공개 Git과 분리하여 무시되는 로컬 submission에만 넣는다.

## 변경과 파일

README의 실제 실행·재배포 안내, `docs/sources.md`, `docs/ai/`, TASK·이슈·검증 기록을 준비했다. `scripts/render_records.py`가 한국어 글꼴과 클릭 가능한 주소·페이지 번호로 TASK PDF와 최종 제출 PDF를 생성한다.

## 최종 이력 수집

`scripts/collect_release.py`는 깨끗한 main, 원격 main 일치, 해당 SHA의 push 자동 배포 성공과 공개 사이트를 확인한 뒤 `submission/release.json`을 만든다. 원본 등록·빈 변경·단순 병합·PDF만의 자동 생성 커밋을 제외하고 각 후보의 파일 목록·이유·링크를 내보낸다.

## 한계와 제출

학습 계획을 완료 결과로 표시하지 않으며 중간 기록의 범위와 한계를 보고서에 명시한다. 최종 SHA는 마지막 문서 커밋 후 로컬 내보내기에서 확정하며 자기 SHA를 넣기 위한 amend를 반복하지 않는다. PDF 시각 검수와 링크·검색 검사를 마친 뒤 사용자에게 전달한다. LMS 제출은 사용자가 완료해야 한다.
