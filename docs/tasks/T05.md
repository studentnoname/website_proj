# T05 — 이미지와 시각 디자인

상태: 구현·시각 검토 완료.

## 현재 디자인과 편집 위치 — 2026-11-06

현재 화면은 검정·라임, 큰 좌우명과 AI로 생성한 크롬·유리 추상 이미지를 사용함. 첫 화면에 관심 분야·백엔드 역할을 배치하고, 본문은 PC 18px·모바일 16px·줄간격 1.75로 통일하였음. 화면은 `site/layouts/landing/list.html`, 공통 스타일·동작은 `site/assets/css/portfolio.css`와 `site/assets/js/portfolio.js`, 메인 이미지는 `site/static/media/resolve-hero.png`를 사용함. 이미지 생성 출처와 실제 화면 검증은 `docs/sources.md` 및 `docs/evidence/T08/firefox/`에 기록하였음.

아래 내용은 2026-10-29 초기 디자인의 작업 이력이며 현재 화면의 편집 경로와 구분함.

## 초기 디자인의 요구사항과 선택

밝은 아이보리·청록·검정과 큰 제목·여백을 사용하였음. 기존 사진은 공개 범위가 미확인이라 사용하지 않고 흐름·병목·학습 방향·작업 과정을 자체 SVG로 표현하였음. 핵심 문장은 실제 HTML 텍스트로 남겼음.

## 초기 디자인의 변경과 파일

네 portfolio 섹션 partial에 SVG title·desc를 넣고 `site/assets/css/portfolio.css`에서 반응형 배치를 정의하였음. 원격 데모 버튼 스크립트를 제거하고 시스템 글꼴을 사용함. HugoBlox baseof·head·라이선스와 제작 고지는 보존하였음. 사용자가 선택하지 않은 원본 콘텐츠 CC 문구는 공개 개인 콘텐츠에 자동 적용하지 않았음.

## 초기 디자인의 실제 검증

1440·768·390px와 200%에서 글·그림·조작을 확인하였음. 이미지 깨짐은 없고 로컬 자산 참조 검사를 통과하였음. I006에서 데모 CV·사진·오래된 출력물을 제거하였음. I008에서 헤더 배경을 불투명하게 바꿔 아래 글자와의 혼선을 없앴음.
