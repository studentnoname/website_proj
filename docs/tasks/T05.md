# T05 — 이미지와 시각 디자인

상태: 구현·시각 검토 완료.

## 최신 재제작 — 2026-11-04 KST

사용자 참고 글과 공식 frontend-design 지침으로 회색·남색, IBM Plex Sans KR, 좌우명의 장식 선, 왼쪽 공통 기준선을 적용했다. 기존 `site/layouts/landing/list.html`, `site/assets/css/portfolio.css`를 수정하고 기존 공통 JS를 재사용했다. 사용하지 않는 이전 장식 PNG는 제거하고 생성 기록은 Git 이력에 보존했다. 글꼴 세 굵기와 SIL OFL 고지는 기존 `assets/media`에서 배포한다. 아래 내용은 최초 구현 시점의 이력이다.

Hugo 빌드, 두 언어 각 18개 참조 검사, Firefox 159.0의 41개 배치·조작 검사, JS 비활성·모션 축소 2개 검사를 통과했다. KO·EN PC·모바일 전체 화면과 계산 스타일을 직접 확인했다. 실제 결과물과 학습 행동에 대한 콘텐츠 결정은 별도로 확인하며, 시각 검증을 P72·P78 충족이나 사용자 승인으로 대신하지 않는다.

## 요구사항과 선택

밝은 아이보리·청록·검정과 큰 제목·여백을 사용했다. 기존 사진은 공개 범위가 미확인이라 사용하지 않고 흐름·병목·학습 방향·작업 과정을 자체 SVG로 표현했다. 핵심 문장은 실제 HTML 텍스트로 남겼다.

## 변경과 파일

네 portfolio 섹션 partial에 SVG title·desc를 넣고 `site/assets/css/portfolio.css`에서 반응형 배치를 정의했다. 원격 데모 버튼 스크립트를 제거하고 시스템 글꼴을 사용한다. HugoBlox baseof·head·라이선스와 제작 고지는 보존했다. 사용자가 선택하지 않은 원본 콘텐츠 CC 문구는 공개 개인 콘텐츠에 자동 적용하지 않았다.

## 실제 검증

1440·768·390px와 200%에서 글·그림·조작을 확인했다. 이미지 깨짐은 없고 로컬 자산 참조 검사를 통과했다. I006에서 데모 CV·사진·오래된 출력물을 제거했다. I008에서 헤더 배경을 불투명하게 바꿔 아래 글자와의 혼선을 없앴다.
