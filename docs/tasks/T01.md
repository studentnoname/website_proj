# T01 — 원본과 개발 환경

상태: 진행 중 / 2026-10-29 KST

## 요구사항과 선택

HugoBlox/kit 공식 Download ZIP과 제공 준비 스크립트 3.1을 사용한다. 상위 `basicproj`와 독립된 제출 저장소를 구성하며 시스템 전역 도구 설정을 바꾸지 않기 위해 실행 도구는 무시되는 `.local/tools/`에 준비했다.

## 실제 수행

1. 기존 인계 파일과 계획서를 보존했다.
2. 공식 ZIP SHA-256 `00a2ccd9e240b2ba4504d95d119d7264ed989805a909cbf954ba70fc1a7998b7`을 확인했다.
3. 임시 원본에서 `identify()`의 `exact=true`, `snapshot_matches=true`를 확인했다.
4. 제공 스크립트를 원본 루트에서 실행하여 종료 코드 0과 `site/`·워크플로 생성을 확인한 뒤 충돌 없이 작업 폴더로 복사했다.
5. 독립 Git 루트를 초기화하고 origin을 `studentnoname/website_proj`로 설정했다. 상위 origin은 변경하지 않았다.
6. 기존 Git 작성자 설정을 사용했다. 보고서 개인정보로 덮어쓰지 않았다.

## 도구

Python 3.12.10, Node 24.20.0, npm 11.19.0, Git 2.55.0.windows.5, Hugo 0.167.0 Extended, Go 1.27.1, Dart Sass 1.105.0.

Claude Code 2.1.287의 로그인과 도구 없는 실제 호출에서 `READY` 응답을 확인했다. 인증 세부 정보는 기록하지 않는다.

## 근거와 남은 작업

`docs/evidence/T01/`에 원본 식별·해시·준비 실행 로그를 보존한다. 의존성 설치와 기본 빌드 결과는 실행 종료 후 추가한다. 기본 빌드가 끝나기 전에는 T01 완료로 표시하지 않는다.
