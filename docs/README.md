# 개발 기록

현재 상태와 완료 근거는 이 디렉터리에서 관리한다. `codex_handoff/records/`는 이전 점검 기록으로 보존하고 현재 실행 결과와 구분한다.

- `handbook/`: 인계 요구사항과 커밋 정책의 작업용 사본.
- `tasks/`: T01~T09 요구사항·선택·변경·검증·한계.
- `issues/`: 실제로 관찰한 문제의 발견·수정·재검증.
- `evidence/`: 실행 로그, 화면, 공개 배포 근거.
- `ai/`: 실제 사용한 요청과 응답 요약. 비밀값·계정 정보 제외.
- `verification.md`: 검사 번호 V01부터 다섯 영역의 실제 동작 기록.
- `commit-log.md`: 원본 등록 제외 기준과 실제 작업 이력 집계.

문서의 시각·버전은 실제 실행에 맞춰 기록한다. 미실행·자료 미제공은 완료로 표시하지 않는다.
