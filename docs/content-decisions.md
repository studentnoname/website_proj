# 공개 콘텐츠 결정

확인일: 2026-10-29 KST

사용자 실제 답변:

> 1. 유학생의 도움을 주기위한 플랫폼과 백엔드
> 2. 없음
> 3.빈칸으로 두기

반영 원칙:

- KONNECT는 유학생을 돕기 위한 플랫폼이고 본인 역할은 백엔드라고 설명한다.
- 공개 가능한 중간 산출물 링크가 없으므로 결과 링크·스크린샷·완료 기능·성능 수치를 만들지 않는다.
- 다음 구체적 학습 행동은 사용자의 요청으로 비워 둔다. 공개 화면에 임의의 계획이나 임시 문구를 넣지 않는다.
- 현재 설명 가능한 활동 과정과 실제 산출물 증빙을 구분한다. P72의 다음 행동과 P78의 실제 결과 증빙은 미충족 가능성이 남는다.
- 기존 사진과 hub 링크는 KONNECT 관련성과 사용 범위가 확인되지 않아 공개 자산·활동 근거에 자동 포함하지 않는다.

## 2026-11-04 원본 기준 재대조

사용자는 참고 글을 반영한 재제작과 함께 “과제에서 요구한 기준들은 절대 어기면 안돼”라고 요청했다. 공개 기준 원문에서 P72는 학습 목표와 구체적 다음 행동, P78은 대표 활동의 실제 산출물과 결과 설명을 요구한다. 앞선 빈칸 결정과 미제공 KONNECT 결과를 그대로 유지하면 두 항목의 충족을 주장할 수 없다.

다음 행동을 `데이터베이스에서 SELECT·JOIN을 실습하고 결과를 정리하기`로 명시하고, 공개 소스·사이트가 실제로 있는 이번 포트폴리오를 추가 대표 활동으로 소개하는 안을 질문했다. 답변 전에는 새 의도나 KONNECT 결과를 만들지 않는다. GitHub를 이 포트폴리오의 소스·이력 관리 및 Actions·Pages 배포에 사용한 사실은 이미 실제 작업으로 확인되어 P73 사례로 설명했다.
